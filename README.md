## ✨ Features

- ✅ **Result Management** - Enter test (30%) and exam (70%) scores, auto-calculate totals
- ✅ **PDF Report Cards** - Generate professional report cards with school letterhead
- ✅ **Student Photos** - Camera integration for student profiles
- ✅ **Attendance Tracking** - Daily attendance with percentage calculation
- ✅ **Psychomotor Skills** - Rate punctuality, neatness, attendance, cooperation, leadership
- ✅ **Comments** - Teacher and principal remarks sections
- ✅ **Signatures** - Official signature lines on all report cards
- ✅ **100% Offline** - No internet required
